Abrir SysAcad ↗

1. Guardá la apariencia

En la computadora, arrastrá este botón a la barra de marcadores del navegador:

Mi facultad · Activar diseño

Si no ves la barra, usá Ctrl + Mayús + B.

Instalación manual / celular

Creá un marcador de cualquier página. Editalo, llamalo “Mi facultad” y reemplazá su dirección por este código completo:

Después abrí SysAcad y elegí el marcador guardado. Algunos navegadores no permiten estos marcadores.

2. Usalo en el sitio oficial

  1. Abrí SysAcad con el botón de arriba.
  2. Ingresá allí con Facultad, Legajo y Contraseña.
  3. Tocá el marcador “Mi facultad” para aplicar el diseño.

Si cambiás de página, activá el marcador otra vez. “Ver diseño original” permite quitar la apariencia.

Tus datos siguen donde corresponden

Esta página de GitHub no recibe tu legajo, contraseña, notas ni materias. El marcador solo agrega estilos en SysAcad y conserva sus formularios, enlaces y acciones. No sincroniza datos con Datalisting y no realiza trámites por su cuenta.

Esto es una mejora visual aplicada al sitio oficial, no un panel independiente conectado a su base de datos. La disponibilidad de SysAcad y sus restricciones del navegador pueden impedir aplicar el diseño.

Activación automática (opcional)

Si ya usás un gestor de scripts de usuario, podés instalar el script de apariencia. Se ejecuta únicamente en el dominio de SysAcad de Paraná.
